# Spring Cloud — Microservices

Cours de microservices avec Spring Cloud et Spring Boot.

## Structure

| Section | Contenu |
|---------|---------|
| [SECTION_02_CREA_MS](./SECTION_02_CREA_MS) | Atelier 01 — Création des microservices `instrument` et `song` |
| [SECTION_03_COMM_MS](./SECTION_03_COMM_MS) | Atelier 02 — Communication inter-microservices avec OpenFeign |
| [SECTION_04_EUREKA](./SECTION_04_EUREKA) | Atelier 03 — Service Discovery avec Netflix Eureka Server & Clients (`song`, `instrument`) |
| [SECTION_05_GATEWAY](./SECTION_05_GATEWAY) | Atelier 04 — Spring Cloud API Gateway (`gatewayserver`) avec routage dynamique |

## Technologies

- Java 21
- Spring Boot 3.4.4
- Spring Cloud 2024.0.1
- Spring Cloud Gateway (Reactive)
- Netflix Eureka (Server & Client Discovery)
- OpenFeign (SECTION_03)
- Spring Data JPA + H2
- Spring Boot Actuator
- Lombok
